# 前端视觉语言：学习工作台

> 参考：用户提供的课程社区截图。只借鉴壳层、信息密度与层级，不复用社区业务语义。

## 视觉原则

- 采用浅灰工作区、白色侧栏和低对比顶栏，让作业卡片自然成为视觉焦点。
- 主文字使用深蓝灰，交互采用沉稳蓝色；官方截止时间、个人计划和状态保持清晰分层。
- 课程、作业、课表和候选审核围绕同一工作台壳层组织，不出现帖子、点赞、投票等社区元素。

## 关键规格

| 区域 | 规则 |
| --- | --- |
| 侧栏 | 桌面端 248px 白底，浅蓝灰选中背景和 3px 蓝色定位线。 |
| 顶栏 | 66px 白底，展示当前位置、轻量搜索占位和本地用户标识。 |
| 内容区 | 最大宽度 1110px，浅灰背景上使用白色卡片承载任务和课程信息。 |
| 卡片 | 9px 圆角、细边框、极轻阴影；作业使用左侧状态色条。 |
| 间距 | 页面 28px、模块 32px、卡片 10–16px，保证信息密度而不拥挤。 |

移动端将侧栏折叠为横向导航，保留相同的页面层级和选中状态。

作业卡片展示课程、标题、简短说明、官方截止、个人计划及提交方式。有 HTTP(S) 提交地址时提供可点击入口。色条与文字标签共同表达紧急程度：官方逾期或有效截止在 24 小时内为红色，3 天内为琥珀色，普通待办为蓝色，截止待确认为灰色，已完成为绿色。官方逾期始终依据官方截止时间；个人计划已过单独标注，不改变官方逾期状态。
