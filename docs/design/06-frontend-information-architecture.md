# 前端信息架构与页面流程

> 参考：[总架构](../architecture.md) · [API 设计](04-api-design.md)  
> 状态：作业优先的双端页面入口已实现。

## 1. 核心原则：先看作业，再看课程

作业是两端的核心视图。用户打开系统首先看到跨已加入课程的待办作业；管理员打开管理工作台首先看到跨全站课程的待审核和已发布作业。课程负责归属、筛选和维护资料，不是发现或处理作业的前置步骤。

`CourseInstance` 仍是共享作业、课表和来源的数据归属边界。页面以作业为中心不改变这一领域关系，也不复制课程或作业数据。

页面层级应满足：

1. 用户不必逐门打开课程，就能看到全部个人作业及官方逾期情况；
2. 管理员不必逐门打开课程，就能发现全站待审核事项、定位已发布作业并修改或撤回；
3. 作业列表上的课程名称与课程筛选提供上下文，课程详情用于进一步查看课表、来源和成员；
4. 管理员端只呈现共享内容管理任务。管理员自己的选课、个人 DDL 和完成状态放在用户端，通过工作台切换进入。

## 2. 两端导航与默认入口

| 工作台 | 默认入口与主导航 | 辅助入口 |
| --- | --- | --- |
| 用户端 | 跨课程“我的作业”；首页可展示同一批作业的近期摘要 | 我的课表、课程目录、通知、已加入课程详情 |
| 管理员端 | 跨课程“作业工作台”，包含待审核候选和已发布作业；可切换审核、已发布、已撤回等状态 | 课程与课表维护、成员和来源处理进度 |

两端导航互不混排。管理员可切换到用户端使用个人功能，但这些功能不在管理员侧栏重复出现。管理员从作业工作台进入某门课程，是为编辑课程资料或查看该课程上下文，不是为了才能找到作业。

## 3. 用户端作业视图

首页首先回答“我最近要做什么”，以作业为主、课表为辅：

1. **临近个人 DDL**：按 `effective_due_at` 升序；
2. **官方已逾期**：单独展示，不因个人计划时间被隐藏；
3. **截止时间待确认**：官方截止时间为空的作业；
4. **最近课表**：作为辅助信息展示。

“我的作业”页提供即将截止、已逾期、待确认、全部分组和课程筛选。后端保证跨课程排序，前端不跨页重新排序。作业卡片至少显示课程名、标题、简要说明、官方截止时间、个人计划截止时间（若有）、完成状态和提交入口（若有）。用户在卡片上编辑个人计划或完成状态，不改变共享作业。

个人计划截止时间为空表示沿用官方截止时间；官方逾期始终只依据官方截止时间判断。用户修改状态后刷新对应分组，跨组作业从当前分组移至新分组。

## 4. 管理员端作业工作台

默认列表覆盖全站课程，并以需要处理的事项优先：

- **待审核**：显示来源、课程、不确定字段和证据；管理员可修改候选后发布或拒绝；
- **已发布**：按官方截止时间组织，支持搜索或按课程筛选、修改共享字段和撤回；
- **已撤回**：保留记录、来源与状态，避免撤回被误解为删除。用户作业列表不显示已撤回作业；
- **处理反馈**：显示来源处理失败或待确认情况，便于管理员发现积压。

每项作业直接带课程标识和必要的来源线索。管理员可以从列表进入课程详情查看上下文，但审核、修改和撤回的主流程不依赖“先选课程”。共享内容变更应让已加入课程的用户知道发生了什么。

## 5. 课程与来源作为辅助视图

用户端课程目录用于自主加入或退出课程；加入后课程详情可查看该课程作业、课表并提交老师文字或附件。课程详情内的作业列表沿用跨课程作业页的排序和字段，不形成另一份作业数据。

管理员端课程页用于创建或修改课程资料、课表，查看成员和来源处理进度。它可以展示当前课程作业以辅助定位与维护，但不承担全站作业的唯一入口。管理员不替用户选课，也不在管理页维护个人 DDL。

来源提交后立即显示任务状态，不等待解析完成。候选审核只展示原始文件名、页码和必要文字证据；原始文件与页面预览不持久化，任务结束后不能回看原页。

## 6. 页面状态与反馈

| 场景 | 页面行为 |
| --- | --- |
| 用户未加入课程 | 课程可在目录中浏览；个人作业和课表不包含该课程 |
| 普通用户访问管理员页 | 服务端拒绝管理操作，页面显示明确权限提示 |
| 文件正在处理或失败 | 展示进度或可读错误，不阻塞浏览作业 |
| 官方 DDL 缺失 | 归入待确认，不伪造日期 |
| 作业修改或撤回 | 管理员列表更新状态；课程成员收到对应通知 |

## 7. 当前实现

用户端保留作业摘要首页和完整跨课程作业页；管理员端默认进入跨课程作业工作台，可审核候选、查看已发布与已撤回作业，并直接修改或撤回。课程页仍维护课程资料、课表、成员和单课程来源进度。

首版仍不做原始课件历史浏览、作业在线提交与评分、学生之间的任务分配或对话式 AI 入口。
