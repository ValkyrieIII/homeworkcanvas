# Homework Canvas 项目架构图

本图对应当前实现：用户端与管理员端共用 Vue 前端项目和 Gin API；API 与 Worker 属于同一 Go 代码库，分别运行。PostgreSQL 保存业务数据，Redis / Asynq 承载异步任务。

```mermaid
flowchart LR
    subgraph Frontend["Vue 前端"]
        User["用户工作台<br/>选课、作业、课表、来源"]
        Admin["管理员工作台<br/>课程维护、候选审核"]
    end

    subgraph Backend["Go 后端（同一代码库）"]
        API["Gin API<br/>身份适配与权限检查"]
        Course["课程与课表"]
        Assignment["共享作业、个人状态与通知"]
        Ingestion["来源与导入"]
        Worker["Asynq Worker<br/>解析 → 定位 → 抽取 → 校验"]
    end

    PG[("PostgreSQL<br/>业务数据与处理状态")]
    Redis[("Redis / Asynq<br/>异步任务")]
    Temp[("临时工作目录<br/>文件、页面与预览")]
    Model["OpenAI 兼容模型服务<br/>按配置调用"]

    User -->|REST| API
    Admin -->|REST| API
    API --> Course
    API --> Assignment
    API --> Ingestion

    Course <--> PG
    Assignment <-->|读取候选；事务发布作业与通知| PG
    Ingestion -->|记录来源与任务| PG
    Ingestion -->|投递任务| Redis
    Ingestion -->|暂存上传文件| Temp

    Redis -->|消费任务| Worker
    Worker -->|候选与任务状态| PG
    Worker <-->|读取并清理| Temp
    Worker -.->|配置模型时调用| Model
```

抽取结果先保存为待审核候选。管理员可以修改、接受或拒绝候选；接受时才在同一数据库事务中创建正式共享作业和站内通知。未配置模型时，Worker 使用本地规则抽取器。上传文件、逐页文本和预览仅在处理期间存放于临时目录。

当前身份适配器使用本地开发请求头；真实登录与生产环境鉴权尚未接入。
